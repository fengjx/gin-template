# 10 PRD

## 功能目标

- 提供可直接执行的初始化命令文档。
- 初始化后默认保留模板历史，并通过 `template` 远程指向模板仓库。
- 让新项目首次执行 `npm install` 后不再出现已知审计告警。

## 用户角色

- 模板使用者
- 模板维护者

## 典型用户流程

- 用户阅读 README，复制初始化命令并执行。
- 脚本克隆模板、保留 git 历史、把模板远程命名为 `template`，完成项目名替换和依赖安装。
- 用户需要同步模板修复时，执行 `git fetch template` 即可获取上游提交。

## 范围内 / 范围外

- 范围内：README 初始化说明、初始化脚本 git 行为、admin lockfile 安全升级、feature 闭环文档。
- 范围外：新增脚手架参数、自动为新项目创建 `origin` 远程、修改业务接口与数据库结构。

## 状态与边界条件

- 支持默认模板仓库地址和用户显式传入 `--repo-url`。
- 对 GitHub SSH 地址做 HTTPS 归一化；非 GitHub 地址保持原样。
- 保留 `.git` 后，初始化脚本仍需继续清理构建产物与模板专属 README 区块。

## 异常与失败路径

- 目标目录已存在且非空时，脚本应继续报错退出。
- 缺少 `git` 或 `perl` 时，脚本维持现有依赖检查并退出。
- 如果未安装 `npm` 或 `go`，脚本继续按现有逻辑跳过对应安装步骤。

## 验收标准

- README 中两处 raw 地址均为 `fengjx/gin-template`，并明确展示模板仓库地址。
- 初始化后保留 `.git`，`git remote -v` 仅显示 `template`，且地址为 HTTPS。
- 生成项目 README 不再包含模板初始化说明块。
- 在生成项目 `admin` 目录执行 `npm audit --json` 时漏洞数为 0。
