# 20 Tech Spec

## 目标与非目标

- 目标：退出登录时正确清理刷新 Cookie
- 非目标：重做整套认证流程

## 现状与约束

- 认证逻辑受现有 token / cookie 约束

## 模块边界

- `internal/biz/auth`
- 可能涉及前端退出逻辑

## 接口与数据流

退出接口返回成功时，服务端主动清理 cookie。

## OpenAPI / 配置 / 数据库影响

- 无契约、配置、数据库变更

## 风险、回滚与观测点

- 风险：清理 cookie 时域配置不一致
- 回滚：恢复旧逻辑并保留调查记录

## 测试与验证策略

- `make test`
- 视触达前端情况追加前端测试
