# 10 PRD

## 功能目标

- Admin 用户可以在后台新增和编辑系统配置。
- 管理员可以查看全部系统配置及其类型、上下线状态。
- JSON 类型配置在后台可以通过简单 JSON 编辑器维护。

## 用户角色

- Admin：查看、创建、编辑、上下线系统配置。

## 典型流程

1. Admin 打开系统配置页，点击“新增配置”。
2. 填写 `key`、`value`、`description`、`is_public`、`type`、`status`。
3. 当选择 `json` 类型时，通过 JSON 编辑器输入并校验内容。
4. 保存成功后列表立即刷新。
5. 当配置被切换为 `offline` 后，对外业务读取不再返回该配置。

## 范围内 / 范围外

- 范围内：`sys_options` 字段扩展、后台新增/编辑、JSON 编辑器、业务读取的上下线控制、相关测试与文档。
- 范围外：批量导入导出配置、配置版本历史、复杂代码高亮编辑器。

## 状态与边界条件

- `type` 仅支持 `string` / `json`。
- `status` 仅支持 `online` / `offline`。
- `json` 类型保存前必须通过 JSON 校验。
- `offline` 配置仍可在后台查看和编辑，但业务读取视为不可用。

## 验收标准

- 后台可新增系统配置并成功落库。
- 列表与详情可展示 `type` 和 `status`。
- JSON 类型非法输入无法提交，且有明确错误提示。
- `/system/about`、`/system/notice`、`pprof_url` 仅读取在线配置。
